# Ma lettre au futur · Ombaliz Thérapie

Sur Render, créer un **Static Site** relié au dépôt GitHub, sur la branche
`main`. Laisser **Root Directory** vide. Indiquer **Build Command**
`node scripts/build-render.cjs` et **Publish Directory** `dist`.

Le script génère le flashcode à partir de l’adresse HTTPS attribuée par Render.
Le PDF et le brouillon sont traités dans le navigateur.
